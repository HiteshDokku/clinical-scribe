# ONC High-Priority List
This dataset includes a partial subset of the ONC High-Priority drug-drug interactions list, specifically filtering for rows where both sides are specific drug names (class-based interactions are skipped).

Note: This is a demo subset of the ONC list and misses are possible.

# High-Risk Drug Classes
The file `high_risk_classes.csv` is a labelling aid and anyone reviewing the medication allow-list must check each drug against it.
