# Frontend Design Direction

This document captures the visual tokens and component patterns used across the clinician-facing UI.

## Live transcript

- `--speaker-clinician: #3E5C6B`
- `--speaker-patient: #5E6B3E`

Pending (not-yet-diarized) utterances render at reduced opacity with no speaker chip. Wait until the utterance actually closes before rendering a guessed label. Verbatim speech is always mono type (`font-mono`). Speakers render as left-aligned rows in a single column. Background and card surfaces use `--paper`/`--paper-2`.
